🚀 Quick Setup

Clone this repo and run the logger:

git clone https://github.com/YOUR_USERNAME/twitch-chat-dashboard.git
cd twitch-chat-dashboard
node twitch-logger.js YOUR_BOT_NAME YOUR_OAUTH_TOKEN valorant_emea2

The logger will create twitch_chat_*.log and twitch_chat_*.jsonl files with live chat.
